# 坦克大战 · Battle City

一个使用纯 HTML + Canvas + JavaScript 实现的经典 **坦克大战（Battle City）** 游戏，单文件、零依赖，直接在浏览器中运行。

## ✨ 功能特性

- 🎮 经典玩法：驾驶坦克守卫基地，消灭所有敌军即可过关
- 🕹️ 键盘控制：方向键 / WASD 移动，空格 / J 开火
- 📱 移动端支持：触屏虚拟方向键 + 开火按钮
- 🧱 多种地形：砖墙（可摧毁）、钢墙、水面（坦克不可通行）、草丛（遮挡视线）
- 👾 4 种敌军：普通、快速、火力、装甲（需 4 发击毁）
- 🎁 道具系统：护盾、强化弹、炸弹、加命
- 📈 多关卡（3 关循环）、得分与最高分记录（localStorage）
- 🔊 Web Audio 音效、爆炸粒子特效、屏幕震动
- ⏸️ 暂停（P）、静音（M）等便捷控制

## 🚀 快速开始

直接双击打开 `index.html`，或使用任意静态服务器：

```bash
# 例如使用 Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

> 也可以直接部署到 GitHub Pages，开箱即用。

## 🎯 操作说明

| 按键 | 功能 |
| --- | --- |
| 方向键 / W A S D | 移动坦克 |
| 空格 / J | 开火 |
| Enter | 开始 / 继续 / 重新开始 |
| P | 暂停 / 继续 |
| M | 静音 / 取消静音 |

## 🛠️ 技术要点

- 基于 `<canvas>` 的像素风格渲染
- 独立的地图/实体/碰撞系统
- 敌军 AI：随机移动 + 概率性瞄准玩家开火
- 固定网格碰撞检测（13×13，每格 32px）
